```
Hueno es una app para identificar colores con la cámara que te dice de qué color es algo con palabras que ya conoces. Apunta el teléfono a cualquier objeto y lee el nombre del color: "Azul oscuro", "Verde claro", "Marrón rojizo". Justo debajo aparecen el nombre exacto del tono y su código de color hex.

Pensada para personas daltónicas, para quien necesita combinar pintura, tela o maquillaje, y para artistas que trabajan del natural.

¿DE QUÉ COLOR ES ESTO?
• Detector de colores en directo: apunta la cámara y el nombre del color aparece al momento

• Lecturas estables: Hueno promedia el área dentro del anillo, así el nombre no parpadea

SABE CUÁNDO FIARTE DE LA LECTURA
• Calibración de blanco con un toque: apunta a una hoja de papel blanco y toca. Hueno corrige la luz de tu habitación

• Honesta por diseño. La cámara de un teléfono no es un instrumento de laboratorio, y Hueno te avisa cuando una lectura no es fiable

COMPARA DOS COLORES
• Captura el color A, apunta al color B, y Hueno te dice si son iguales, parecidos o distintos

• Útil para distinguir cables, revisar luces de estado, combinar ropa o comparar un color de pintura con una pared

COLOR DE UNA FOTO

GUARDA Y ORGANIZA
```

## Keywords and why

| Keyword | Where | Why |
|---|---|---|
| identificar colores | Title, first sentence | Most direct way to say "color identifier" as a search; a verb phrase reads naturally in a title |
| detector de colores | Short description, long description | Common product term in Spanish, maps to "color detector" |
| daltónico / daltónicos / daltonismo | Short description, long description (section heading + body) | Spanish users search the condition name, not "color blind"; both the adjective and the noun are used |
| nombre del color / nombres de colores | Long description (several times) | Main promise of the app, maps to "color name" |
| código de color / código hex | First paragraph, photo section | Maps to "hex color code"; "hex" kept as is because Spanish designers use it |
| color de una foto | Section heading | Maps to "color picker from image"; "selector de color" is less common with everyday users |
| comparar colores | Section heading | Maps to "compare two colors" |
| buscador de colores, reconocimiento de colores | Long description, once each | Map to "color finder" and "color recognition"; long tail, used once to avoid stuffing |
| color de pintura | Long description | Maps to "paint color"; mentioned lightly like en-US, not targeted |
| cámara | Short description, first sentence | Many searches pair the keyword with "cámara" |

Policy check: no "mejor", "gratis", "n.º 1", no emoji, no competitor names, no all-caps title. "arsénico" and "camel" are color names, as in en-US. Section headings are in caps like en-US.

## Notes for es-419

The text avoids most regional words, so one listing can serve both. If you make a separate es-419 listing, consider:

- "marrón" → "café" is common in Mexico and Central America; keep "marrón" in the title-level keywords, since it is understood everywhere. (App color names also use "Marrón".)
- "Bricolaje y hogar" → "Proyectos en casa" ("bricolaje" is mainly Spain).
- "Costura, punto y manualidades" → "Costura, tejido y manualidades" ("punto" for knitting is Spain).
- "video" is used in both the app and listing; in Spain "vídeo" is the more common spelling. For a Spain-only listing you could write "vídeo".
- Title and short description need no change.
