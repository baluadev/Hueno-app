## Full description (1703/4000)

```
Hueno는 카메라로 색상을 인식해서, 무슨 색인지 누구나 아는 쉬운 말로 알려 주는 앱이에요. 휴대폰을 물건에 비추기만 하면 "남색", "밝은 초록", "적갈색"처럼 색 이름이 바로 나타나요. 바로 아래에는 더 자세한 색 이름과 헥스 컬러 코드(HEX)도 함께 표시돼요.

색약이나 색맹이 있는 분, 페인트·옷감·화장품 색을 맞춰야 하는 분, 실물을 보며 그림을 그리는 분을 위해 만들었어요.

이거 무슨 색이지?
• 실시간 색깔 찾기: 카메라를 비추면 색 이름이 바로 나타나요
• 쉬운 색 이름 먼저 (빨강, 주황, 노랑, 초록, 파랑, 보라, 분홍, 갈색, 회색, 검정, 흰색), 밝은 색과 어두운 색까지 구분
• 정확한 색이 필요할 때는 자세한 색 이름과 헥스 코드 제공
• 버튼을 누르면 색 이름을 소리로 읽어 줘요
• 안정적인 측정: 원 안의 영역을 평균 내서 색 이름이 깜빡이지 않아요

측정 결과를 믿어도 되는지 알려 줘요
• 한 번에 끝나는 흰색 보정: 흰 종이를 비추고 누르기만 하면 방 안 조명에 맞게 색을 보정해요
• 신뢰도 표시: 양호, 보통, 불량으로 알려 주고 "너무 어두워요, 조명을 더하세요" 같은 도움말도 보여 줘요
• 솔직한 설계. 휴대폰 카메라는 측정 장비가 아니기 때문에, 측정이 불안정하면 Hueno가 그렇다고 알려 드려요

두 가지 색 비교
• 색 A를 저장하고 색 B를 비추면 같음, 비슷함, 다름으로 알려 줘요
• 어떻게 다른지도 알려 줘요: "A는 파란색 계열, B는 초록색 계열이에요. B가 조금 더 밝아요."
• 전선 구분, 상태 표시등 확인, 옷 매칭, 벽에 대 보며 페인트 색 맞추기에 유용해요

사진 색상 추출
• 사진이나 스크린샷을 열고 눌러서 색을 골라요
• 확대한 뒤 원을 움직여 픽셀 하나의 색까지 찾을 수 있어요
• 헥스 컬러 코드를 한 번에 복사

쉬운 말로 알려 주는 색약·색맹 도우미
많은 색상 앱은 "번트 시에나"나 "카멜" 같은 이름으로 답해요. Hueno는 먼저 색 계열을 알려 주고, 그다음 밝기와 진하기를 알려 줘요. 적록색약이든 다른 유형의 색각 이상이든, 바로 판단할 수 있는 답을 얻을 수 있어요. 어느 전선인지, 어느 셔츠인지, 그래프의 어느 선인지요. TalkBack과 큰 글씨에서도 잘 작동해요.

저장하고 정리하기
• 저장한 색의 기록, 색마다 이름과 코드 함께 보관
• 색에 이름을 붙이고 컬렉션으로 묶기
• Pro에서 CSV로 내보내기

배려하는 광고, 공정한 업그레이드
• 카메라 화면과 사진 화면에는 광고가 나오지 않아요
• 하던 일을 방해하는 전면 광고가 없어요
• Hueno Pro는 구독이 아닌 한 번 구매예요. 광고를 없애고 기록 무제한, 비교 무제한, 방마다 보정 저장 기능을 열어 줘요
• 아직 구매가 망설여진다면? 짧은 동영상 하나를 보고 Pro를 6시간 동안 사용해 보세요

이런 분들이 Hueno를 써요
• 일상 속 물건의 색깔을 찾고 싶은 색약·색맹 사용자
• DIY와 집 꾸미기: 사러 가기 전에 페인트 색 확인
• 바느질, 뜨개질, 공예: 실, 털실, 원단 색 맞추기
• 그림 그리는 분: 참고 자료 속 그림자와 피부 톤의 실제 색 찾기
• 디자이너와 개발자: 실제 사물에서 컬러 코드 가져오기

알아 두세요
색 측정 결과는 카메라와 조명에 따라 달라져요. 가장 믿을 만한 결과를 얻으려면 낮의 자연광이나 밝은 흰색 조명 아래에서 먼저 보정하세요. Hueno는 참고용 도구예요. 의료기기나 공인 색상 측정 장비가 아니에요.
```

## Từ khóa và lý do

Không có số liệu lượng tìm kiếm cho thị trường Hàn (chưa tra gợi ý tìm kiếm Play ko-KR). Danh sách dưới đây là phán đoán dựa trên cách người Hàn thường gọi tính năng này; cần kiểm lại bằng gợi ý tìm kiếm Play ở Hàn Quốc và báo cáo từ khóa trong Play Console sau 4–6 tuần.

| Từ khóa | Vị trí | Lý do |
|---|---|---|
| 색상 인식 | Tên, câu đầu mô tả dài | Tương đương "color identifier"; cách nói chuẩn, trung tính |
| 색깔 / 색 이름 / 이름 찾기 | Tên | "색깔" là từ đời thường (người dùng hay gõ hơn "색상"); "색 이름" là lời hứa chính của app (color name) |
| 색깔 찾기 | Mô tả ngắn, mô tả dài | Tương đương "color finder"; cụm tự nhiên khi hỏi "màu gì" |
| 색약, 색맹, 색약·색맹 도우미 | Mô tả ngắn, một mục riêng | Tương đương "color blind helper". Ở Hàn "색약" (yếu màu) phổ biến hơn "색맹" cho đa số người dùng thực tế, nên dùng cả hai |
| 적록색약, 색각 이상 | Mô tả dài | Cụm cụ thể hơn, đuôi dài; "색각 이상" là thuật ngữ trung tính |
| 컬러 코드 / 헥스 컬러 코드 / HEX | Mô tả ngắn, mô tả dài | Tương đương "hex color code"; nhóm designer/dev hay gõ "컬러 코드" |
| 사진 색상 추출 | Tiêu đề mục trong mô tả dài | Tương đương "color picker from image"; "색상 추출" là cách gọi quen thuộc |
| 무슨 색 (이거 무슨 색이지?) | Tiêu đề mục | Tương đương "what color is this"; đúng câu người dùng tự hỏi |
| 색 비교 / 두 가지 색 비교 | Tiêu đề mục | Tương đương "compare two colors" |
| 페인트 색 | Mô tả dài, nhắc nhẹ | Giống en-US: chỉ nhắc, không nhắm |

Không dùng: "무료", "최고", "1위", emoji, tên đối thủ hay thương hiệu khác. "번트 시에나" và "카멜" là tên màu (thay cho "arsenic", "camel" của bản en-US, vì "비소색" không ai dùng trong tiếng Hàn).
